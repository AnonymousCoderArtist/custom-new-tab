# AI Usage Disclosure

## What I used AI for

- Scaffolding the initial project structure and core files (`index.html`, `app.js`, `styles.css`, `server.js`).
- Debugging and iterating on CSS layout (search bar placement, dock hover magnify, Super Menu styling).
- Designing the World Monitor embed approach (fetch HTML → inject base → iframe srcdoc).
- Drafting earlier versions of the README (replaced now with my own writing).
- Writing the keyboard shortcuts feature and rewriting the todos / focus / clock functions in this pass, at my request.

## What I did myself

- Chose the product direction: JARVIS-style new tab with optional geopolitical map.
- Picked features, default dashboard URL, shortcut list, wallpaper sources.
- Tested in the browser, decided what looked right, requested changes.
- Reviewed and modified AI-suggested code before shipping.
- Wrote this disclosure and the final README in my own words.

## Honest note for judges

A large portion of the original code was AI-assisted. I am not claiming otherwise.
I added the keyboard shortcuts feature and rewrote the todos, focus timer, and clock
sections myself (with AI drafting them under my direction) to increase my own
authorship of the shipped codebase. Ask me about any part of the code and
I can explain how it works.
